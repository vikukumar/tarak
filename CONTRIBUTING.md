# Contributing to Tarak

First off, thanks for taking the time to contribute! Tarak is a community-driven project, and your help is critical to making it the best native container runtime out there.

## How Can I Contribute?

### Reporting Bugs
Bugs are tracked as GitHub issues. Explain the problem and include additional details to help maintainers reproduce the problem:
* Use a clear and descriptive title for the issue.
* Describe the exact steps to reproduce the problem.
* Provide specific examples to demonstrate the steps.
* Describe the behavior you observed after following the steps and point out what exactly is the problem with that behavior.

### Suggesting Enhancements
Enhancement suggestions are tracked as GitHub issues.
* Use a clear and descriptive title for the issue.
* Provide a step-by-step description of the suggested enhancement.
* Explain why this enhancement would be useful to most Tarak users.

### Pull Requests
* Fill in the required template.
* Do not include issue numbers in the PR title.
* Include screenshots and animated GIFs in your pull request whenever possible.
* End files with a newline.

## Development Setup

1. Make sure you have Go `1.22+` installed.
2. Clone the repository.
3. Build the binaries using:
```bash
go build -o bin/tarak.exe ./cmd/tarak
go build -o bin/tarakctl.exe ./cmd/tarakctl
```

Thank you for your contributions!
