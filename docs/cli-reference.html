CLI & Command Suite

CLI Reference

Command-line syntax and usage guide for tarakctl (or alias taraktl).

💻 Core Cluster Commands

Command Aliases Description
tarakctl get pods po List all pods across namespaces
tarakctl get nodes no List all cluster control plane & worker nodes
tarakctl apply -f <file> — Create or update resources declaratively from YAML
tarakctl tunnel list tunnels, tun ls List live Cloudflare and Tailscale tunnel endpoints
tarakctl logs <pod> — Stream real-time logs from a container pod
tarakctl delete <kind> <name> — Delete a cluster resource
