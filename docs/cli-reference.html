💻 CLI Reference Guide

Complete command-line reference for tarakctl (and tarak).

Core Commands

Command Description Example
apply -f <file> Create or update resources from a YAML manifest tarakctl apply -f app-sample.yml
get <resource> List pods, services, deployments, nodes, or CRDs tarakctl get all -A -o wide
describe <type> <name> Show detailed metadata and lifecycle events tarakctl describe pod/web-app -n demo
port-forward <pod> <local:remote> Forward a local port to a container port tarakctl port-forward pod/web 8080:80
logs <pod> Stream container output logs tarakctl logs pod/web -f
exec <pod> -- <cmd> Execute a command inside a running container tarakctl exec pod/web -it -- /bin/sh
top <pods/nodes> Display live CPU and memory utilization tarakctl top pods -n demo
version Display client and server version information tarakctl version

Server & Node Commands

Command Description Example
tarak init Bootstrap cluster PKI, state store, and admin kubeconfig tarak init --data-dir ~/.tarak/data
tarak server Start the unified API server and container engine tarak server --bind-address 0.0.0.0:6443
tarak agent Start the dedicated worker runtime node tarak agent --server https://cluster:6443
