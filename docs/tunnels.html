Edge & Mesh Networking

Inbuilt Tunnels & Ingress

Zero-configuration public endpoints via Cloudflare and secure private mesh sharing via Tailscale MagicDNS.

☁️ 1. Inbuilt Cloudflare Tunnels

Start Tarak with --cloudflare-tunnel to instantly generate a public HTTPS URL without port forwarding:

# Quick Tunnel (Zero config): tarak --cloudflare-tunnel # Named Tunnel (Persistent custom domain): tarak --cloudflare-tunnel --cloudflare-token <YOUR_TOKEN>

🔒 2. Tailscale Private Mesh Sharing

Join your cluster to your private Tailnet mesh:

tarak --tailscale --tailscale-authkey <tskey-auth-...>

🌐 3. Native Ingress Resource Example

Route incoming traffic directly to your backend services using ingressClassName: tarak-cloudflare or tarak-tailscale:

apiVersion: networking.k8s.io/v1 kind: Ingress metadata: name: app-ingress namespace: default spec: ingressClassName: tarak-cloudflare rules: - host: app.vikshro.in http: paths: - path: / pathType: Prefix backend: service: name: web-app-svc port: number: 80

📊 4. Inspect Live Tunnel Status

List active tunnels from the command line:

tarakctl tunnel list # Output: # TYPE STATUS MODE PUBLIC URL AGE # CLOUDFLARE Active quick-tunnel https://random-subdomain.trycloudflare.com 5m # TAILSCALE Active magic-dns https://tarak-node.ts.net 5m
