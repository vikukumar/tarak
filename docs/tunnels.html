Host Auto-Discovery

⚡ Host Auto-Detection & Automated Node Synchronization

Zero-Config Active

Tarak automatically inspects the host system for existing cloudflared or tailscale binaries, daemon sockets, CGNAT 100.64.0.0/10 interfaces, and environment tokens. When detected:

☁️ Cloudflare Auto-Register

Instantly activates public HTTP ingress through Cloudflare Quick/Named Tunnels with automatic SSL without touching router ports.

🛡️ Tailscale WireGuard Auto-Mesh

Joins private Tailnet, registers MagicDNS, and propagates secure encrypted node-to-node tunnels to newly registered cluster nodes.

Networking Engine

1. Inbuilt Container Network Interface (CNI)

Tarak includes a zero-dependency CNI engine providing deterministic IP address management, pod-to-pod routing, CoreDNS resolution, and service proxies:

Subnet / Component CIDR / Allocation Purpose
Pod CIDR 10.244.0.0/16 Allocated in /24 blocks per worker node (up to 250 pods per node)
Service CIDR 10.96.0.0/12 Virtual ClusterIP range with integrated load balancer proxy
CoreDNS Server 10.96.0.10 Internal cluster DNS resolver for service discovery
Public Ingress

2. Cloudflare Ingress Tunnels

Expose your cluster endpoints to the public internet instantly without port forwarding, dynamic DNS, or public static IPs:

# Quick ephemeral tunnel (instant free trycloudflare URL): tarak server --cloudflare-tunnel # Named persistent tunnel (custom domain): tarak server --cloudflare-tunnel --cloudflare-token <YOUR_TOKEN>
Private Mesh

3. Tailscale Private WireGuard Mesh

Create an end-to-end encrypted mesh interconnecting distributed cloud VMs, home labs, and edge nodes on your private Tailnet:

# Start control plane with Tailscale mesh: tarak server --tailscale --tailscale-authkey <tskey-auth-...> # Or configure worker agent to join through Tailscale IP: taraks --server https://100.x.y.z:6443 --token <cluster-token>
