Cluster Architecture

Multi-Node Clustering Guide

Scale your workloads across multiple physical servers, VMs, or edge nodes with 1 Control Plane and N Workers.

🏗️ Step 1: Start the Control Plane Server (tarakd)

On your primary master node, launch the dedicated API server:

tarakd --listen-addr 0.0.0.0:8443 --token my-cluster-secret-token

⚡ Step 2: Join Worker Nodes (taraks)

On every worker server or VM, start the node runtime agent pointing to the server:

taraks --server https://192.168.1.50:8443 \ --token my-cluster-secret-token \ --node-name worker-node-01

The worker automatically registers with the control plane, inspects local CPU/memory capacity, and sends periodic status leases.

🔍 Step 3: Verify Nodes with CLI

Run tarakctl get nodes to view all active cluster nodes:

tarakctl get nodes # Output: # NAME STATUS ROLES AGE VERSION # master-node Ready controlplane 15m v1.0.1 # worker-node-01 Ready worker 2m v1.0.1 # worker-node-02 Ready worker 1m v1.0.1
