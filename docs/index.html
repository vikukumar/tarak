TARAK — Next-Generation Container Orchestrator

A pure Go, zero-dependency orchestrator that runs anywhere. 10x faster and 20x lighter than Kubernetes & K3s.

Key Features

  • Zero External Dependencies: Runs without Docker Desktop, WSL2, containerd, or etcd.
  • Ultra-Lightweight Footprint: ~22MB RAM idle consumption with <180ms startup.
  • Inbuilt Cloudflare & Tailscale: Zero-configuration public HTTPS tunnels and private mesh sharing.
  • Multi-Node Clustering: Seamless 1 Control Plane + N Worker Nodes across clouds and bare-metal.
  • Kubernetes API Compatibility: Declarative YAML support for Deployments, Pods, Services, and Ingresses.
