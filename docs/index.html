⚡

Native OCI Extraction

Directly downloads, caches, and unpacks OCI layers from Docker Hub to disk. No background daemon or socket bridge needed.

🌐

Virtual Pod Bridge

High-performance virtual network namespaces providing isolated container IP addressing, port-forwarding, and load balancing.

📦

All-in-One Binary

Control plane API server, controller loops, worker node runtime, and CLI control tool bundled into a single zero-dependency binary.

🛡️

Zero-Trust PKI Security

Automated mutual TLS (mTLS) with internal Certificate Authority (CA) generation and native TarakSecurityPolicy enforcement.

💻

Universal Cross-Platform

Runs identically across Windows (AMD64/ARM64), Linux (AMD64/ARM64), and macOS (Apple Silicon / Intel).

🔌

Reusable Go SDK

Import pkg/client directly into your own Go programs to automate, orchestrate, and manage workloads programmatically.
