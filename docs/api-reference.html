REST & OpenAPI

API Reference

Full documentation of Tarak's Kubernetes-compatible REST endpoints, discovery APIs, and custom resources.

📡 Core Workload & System Endpoints

Method Endpoint Path Description
GET /api/v1/namespaces/{ns}/pods List or watch pods with query selector
POST /api/v1/namespaces/{ns}/pods Create and schedule a new pod
GET /apis/apps/v1/namespaces/{ns}/deployments List active deployments
GET /apis/networking.k8s.io/v1/ingresses List ingress rules and active routes
GET /apis/networking.tarak.io/v1/tunnels List Cloudflare and Tailscale tunnel status
GET /healthz & /livez Health & liveness probes
