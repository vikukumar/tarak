📡 REST & OpenAPI Reference

Comprehensive API endpoint documentation for Tarak control plane, Kubernetes compatibility layer, and native extensions.

Core API Group (/api/v1)

Method & Endpoint Resource Description
GET /api/v1/namespaces NamespaceList List all active namespaces in the cluster
POST /api/v1/namespaces Namespace Create a new namespace
GET /api/v1/namespaces/{ns}/pods PodList List all pods within a namespace
POST /api/v1/namespaces/{ns}/pods Pod Submit and schedule a new pod container
DELETE /api/v1/namespaces/{ns}/pods/{name} Status Gracefully stop and terminate a pod container
GET /api/v1/namespaces/{ns}/services ServiceList List ClusterIP & LoadBalancer services
GET /api/v1/nodes NodeList List all control plane and worker nodes
POST /api/v1/nodes Node Register a new worker node to the cluster
PUT /api/v1/nodes/{name}/status Node Worker node heartbeat & condition report

Apps API Group (/apis/apps/v1)

Method & Endpoint Resource Description
GET /apis/apps/v1/namespaces/{ns}/deployments DeploymentList List deployments across replicas
POST /apis/apps/v1/namespaces/{ns}/deployments Deployment Create declarative deployment with rolling updates
DELETE /apis/apps/v1/namespaces/{ns}/deployments/{name} Status Delete a deployment and cascade replicas

Native Extensions (/apis/*.tarak.io/v1)

Method & Endpoint Description
GET /apis/runtime.tarak.io/v1/version Get native TCR engine build, OS isolation mode, and features
GET /apis/runtime.tarak.io/v1/status Get host hardware utilization, memory usage, and running containers
POST /apis/security.tarak.io/v1/taraksecuritypolicies Create declarative zero-trust egress/ingress security policies

Discovery & Health Endpoints

Endpoint Description
GET /healthz, /livez, /readyz Cluster liveness and readiness probe endpoints (HTTP 200 OK)
GET /version Kubernetes GitVersion and Tarak version metadata
GET /openapi/v2 Full OpenAPI v2 (Swagger) schema definition for API clients
GET /metrics Prometheus exposition format cluster metrics
