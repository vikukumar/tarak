🚀 Getting Started with Tarak

Learn how to install, bootstrap a cluster, deploy container workloads, and interact via CLI or Go SDK.

1. Installation

Install Tarak using one-line scripts or download pre-compiled binaries:

Linux / macOS:

curl -fsSL https://raw.githubusercontent.com/vikukumar/tarak/main/install.sh | bash

Windows (PowerShell):

irm https://raw.githubusercontent.com/vikukumar/tarak/main/install.ps1 | iex

2. Start the Cluster

Start the unified Tarak API Server and Native Container Engine:

tarak server

This automatically creates the PKI certificates, starts the BoltDB state store, initializes the local node, and begins listening on https://127.0.0.1:6443.

3. Deploy a Workload

Deploy a standard Kubernetes YAML manifest. Tarak will download the OCI image layers and run the container directly:

tarakctl apply -f app-sample.yml

Check running pods:

tarakctl get pods -n demo -o wide

4. Access Your Container

Forward traffic to the pod and view your application in the browser:

tarakctl port-forward pod/web-app-pod 8080:80 -n demo

Open http://localhost:8080 in your browser to see your live container!
