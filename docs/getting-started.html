Quickstart Guide

Get Started with TARAK

Install Tarak with a single command, start a lightning-fast cluster, and deploy your first workload.

⚡ 1. One-Line Installation

Choose your platform script to install all 4 core binaries (tarak, tarakd, taraks, tarakctl):

# Linux & macOS: curl -fsSL https://tarak.vikshro.in/install.sh | bash # Windows (PowerShell): irm https://tarak.vikshro.in/install.ps1 | iex

🚀 2. Start Tarak All-in-One Engine

Launch both the control plane server and local worker runtime in a single command:

tarak

📦 3. Deploy Your First Application

Apply your application manifest containing Deployment, Service, and Ingress:

tarakctl apply -f app-sample.yml

Verify active pods and endpoints:

tarakctl get pods tarakctl get services tarakctl tunnel list

🔧 4. Reusable Go Client SDK

Integrate Tarak directly into your Go microservices and tools:

go get -u github.com/vikukumar/tarak/pkg/client@latest
package main import ( "context" "fmt" "github.com/vikukumar/tarak/pkg/client" ) func main() { c, _ := client.NewClient("https://127.0.0.1:8443", client.WithInsecure()) pods, _ := c.Pods("default").List(context.Background()) fmt.Printf("Active pods: %d\n", len(pods.Items)) }
